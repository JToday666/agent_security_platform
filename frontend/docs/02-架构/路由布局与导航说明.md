# 路由布局与导航说明

本文档说明前端路由树如何组织、布局如何切换、导航如何生成，以及鉴权与滚动恢复如何工作。

## 1. 路由总入口

路由总入口是 `src/app/router/router.ts`。

它做了三件事：

- 把 `publicRoutes`、`userRoutes` 和 `notFoundRoute` 合成完整路由树
- 注册 `scrollBehavior`
- 调用 `registerRouteGuards(router)` 挂载全局鉴权守卫

路由来源文件：

- `src/app/router/modules/public-routes.ts`
- `src/app/router/modules/user-routes.ts`
- `src/app/router/route-names.ts`
- `src/app/router/route-guards.ts`

## 2. 路由分组

### 2.1 公共路由

公共路由挂在 `PublicLayout.vue` 下：

`/` 会重定向到运行时首选 locale 对应的 `/:locale` 首页，表格中的路径均为真实路由树路径。

| 路径                           | 路由名            | 页面组件                                        | 备注             |
| ------------------------------ | ----------------- | ----------------------------------------------- | ---------------- |
| `/:locale`                     | `HomePage`        | `HomePage.vue`                                  | 首页             |
| `/:locale/dataset`             | `DatasetList`     | `DatasetCatalogPage.vue`                        | 开启会话滚动恢复 |
| `/:locale/dataset/:datasetId`  | `DatasetDetail`   | `DatasetDetailPage.vue`                         | 开启会话滚动恢复 |
| `/:locale/leaderboard`         | `LeaderboardPage` | `modules/leaderboard/pages/LeaderboardPage.vue` | 公共页           |
| `/:locale/contact`             | `ContactPage`     | `ContactPage.vue`                               | 公共页           |
| `/:locale/:pathMatch(.*)*`     | `NotFoundPage`    | `NotFoundPage.vue`                              | 404              |

### 2.2 工作台路由

工作台路由挂在 `UserLayout.vue` 下，统一带 `meta.requiresAuth = true`：

| 路径                                      | 路由名             | 页面组件                    | 备注         |
| ----------------------------------------- | ------------------ | --------------------------- | ------------ |
| `/:locale/user`                           | `UserCenter`       | `EvaluationRecordsPage.vue` | 评测记录列表 |
| `/:locale/user/evaluation/:evaluationId`  | `EvaluationDetail` | `EvaluationDetailPage.vue`  | 评测详情     |
| `/:locale/user/agents`                    | `AgentManagement`  | `AgentManagementPage.vue`   | Agent 管理   |
| `/:locale/user/agents/register`           | `AgentRegister`    | `AgentRegisterPage.vue`     | 注册 Agent   |
| `/:locale/user/agents/:agentId`           | `AgentDetail`      | `AgentDetailPage.vue`       | Agent 详情   |
| `/:locale/user/submit`                    | `AgentSubmit`      | `SubmitAgentPage.vue`       | 提交评测     |
| `/:locale/user/profile`                   | `UserProfile`      | `ProfilePage.vue`           | 个人资料     |

## 3. 命名路由对象

`src/app/router/route-names.ts` 统一维护两类内容：

- `ROUTE_NAME`
  路由名常量，避免散落硬编码字符串
- `RouteLocation`
  命名跳转对象和动态参数工厂，例如 `datasetDetail(datasetId)`、`evaluationDetail(evaluationId)`

这个文件是前端页面间跳转的单一入口，页面内部应优先依赖它，而不是手写路径字符串。

## 4. 布局与导航外壳

### 4.1 布局文件

- `src/app/layouts/PublicLayout.vue`
  顶部挂 `NavBarShell`，正文只渲染公共页面
- `src/app/layouts/UserLayout.vue`
  顶部挂 `NavBarShell`，正文采用“左侧 sticky 侧边栏 + 右侧主内容区”的双列布局，工作台页面在右列铺满剩余宽度

### 4.2 顶部导航与侧边栏

导航相关文件集中在 `src/app/shell/`：

- `nav-items.ts`
  声明公共导航、工作台导航、工作台侧边栏导航项
- `nav-link-state.ts`
  根据导航项的 `exact` 配置生成 `router-link` 激活态参数
- `shell-context.ts`
  根据当前路由名判断当前处于 `public` 还是 `workspace`
- `NavBarShell.vue`
  顶部导航条容器。负责拼装桌面导航、移动抽屉和用户入口
- `useNavBarShell.ts`
  顶部导航状态组合。负责滚动隐藏、移动菜单、登录入口和个人资料跳转
- `DesktopNavBar.vue`
  桌面顶部导航。负责品牌入口、主导航、次级导航、语言切换、登录按钮和移动菜单按钮
- `MobileNavDrawer.vue`
  移动端导航抽屉。负责登录入口、用户入口、语言切换、主导航和次级导航
- `LanguageSwitcher.vue`
  顶部导航语言切换器。桌面端位于次级入口右侧、用户入口左侧；移动端位于抽屉用户入口后。切换时通过 URL locale 驱动现有国际化同步链路
- `UserNavMenu.vue`
  用户头像、用户名和个人资料入口
- `UserSidebarShell.vue`
  工作台 sticky 侧边栏。负责渲染工作台导航项、收起/展开和宽度同步

导航项由 `nav-items.ts` 中的构建函数按当前语言生成：

- `buildExploreNavItems(t)`
  首页、数据集目录、排行榜、联系我们
- `buildWorkspaceNavItems(t)`
  评测记录、智能体管理、注册智能体、提交评测
- `buildWorkspaceSidebarItems(t)`
  工作台侧边栏，在工作台导航基础上增加个人资料

## 5. 鉴权守卫

`src/app/router/route-guards.ts` 中的 `registerRouteGuards(router)` 是工作台路由的统一鉴权入口。

核心规则：

- 只要目标路由命中的任一 record 带 `meta.requiresAuth`
- 守卫会先等待 `userStore.initPromise` 完成，再检查 `userStore.isLogin`
- 如果最终仍未登录，就会：
  1. `userStore.setPostLoginRedirect(to.fullPath)` 保存原始目标页
  2. `userStore.openLoginDialog()` 打开登录弹窗
  3. 返回 `RouteLocation.home`，统一跳回首页

这样做的结果是：

- 登录入口可以集中管理
- 登录成功后仍然能回到原目标页
- 页面组件本身不需要重复写鉴权跳转逻辑

## 6. 会话滚动恢复

`src/app/router/router.ts` 还负责会话级滚动恢复。

实现方式：

- 对带 `meta.restoreSessionScroll = true` 的页面生成专属 key
- 进入页面时在 `scrollBehavior` 里尝试读取 `sessionStorage` 中保存的位置
- 离开页面时，在 `beforeEach` 里把当前 `window.scrollY` 存回去

辅助工具集中在：

- `src/shared/lib/session-scroll-state.ts`

当前启用这一能力的页面：

- `DatasetCatalogPage.vue`
- `DatasetDetailPage.vue`

这让用户在“目录 -> 详情 -> 返回目录”的场景下更容易回到原阅读位置。
