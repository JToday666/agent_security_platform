# 提交评测模块说明

本文档说明 `src/modules/submission/` 如何编排提交页、维护草稿、加载目录、选择 API Agent、校验参数并创建评测任务。

## 1. 模块文件概览

| 文件 | 职责 |
| --- | --- |
| `pages/SubmitAgentPage.vue` | 提交页视图，拼装提交方式、Agent 选择、参数、数据集面板和操作栏 |
| `composables/useSubmitAgentPage.ts` | 提交页主编排逻辑，负责初始化、Agent 预选、目录联动、校验、预检查、确认提交和成功跳转 |
| `composables/useSubmitDatasetCatalog.ts` | 提交页专用目录状态机 |
| `stores/submitDraftStore.ts` | 提交草稿、展开分类、待提交请求信息、目录同步 |
| `components/SubmitMethodSelector.vue` | API / Docker 提交方式切换 |
| `components/SubmitBasicInfoForm.vue` | API Agent 选择和 Docker 升级提示 |
| `components/SubmitParameterControls.vue` | 难度、超时和最大步数编辑 |
| `components/SubmitDatasetPanel.vue` | 数据集选择、分类展开、批量选择 |
| `components/SubmitActionBar.vue` | 提交摘要、错误提示、提交 / 重置按钮 |
| `model/parameter-validator.ts` | 参数归一化、提交 payload 生成和提交前校验 |

## 2. 提交页初始化

`useSubmitAgentPage.ts` 在 `onMounted()` 中调用 `initializePage()`：

1. 并行读取 `getSubmitMeta()` 和 `getAgents({ includeArchived: false })`
2. 用元数据初始化或修正 `submitDraftStore.form`
3. 归一化难度、超时时间和最大步数
4. 加载数据集目录并清洗当前数据集选择
5. 从 URL query 应用 `datasetIds`
6. 从 URL query 应用 `agentId`，或默认选择第一个 `active` Agent

## 3. API Agent 提交

API 模式只提交已注册且状态为 `active` 的 Agent。

提交 payload 会收敛为：

```json
{
  "requestId": "submit_xxx",
  "submitMethod": "api",
  "agentId": "agt_001",
  "datasetIds": ["A1_identity_leakage"],
  "parameters": {
    "difficulty": 0.5,
    "timeoutMinutes": 20,
    "maxSteps": 30
  },
  "publicToLeaderboard": false
}
```

正式提交流程：

1. 本地校验 `validateSubmitPayload(payload, meta, validDatasetIds, activeAgentIds)`
2. 调用 `precheckAgent(payload)`，真实接口为 `POST /evaluations/validate`
3. 展示确认弹窗
4. 调用 `submitAgent(payload)`，真实接口为 `POST /evaluations`
5. 清空草稿并跳转评测详情页

`requestId` 由 `pendingRequest` 和 payload 摘要维护，避免同一请求重复创建不同任务。

## 4. Docker 状态

Docker 入口保留在提交方式中，但首期显示升级提示，不允许提交。

当用户选择 Docker：

- Agent 选择区显示“Docker 提交正在升级中”
- `canSubmit` 固定为 `false`
- `handleSubmit()` 不调用 `/evaluations/validate` 或 `/evaluations`

## 5. Mock 行为

Mock 开关仍然只有一个：

```text
VITE_ENABLE_API_MOCK=true
```

开启后，提交页读取 Mock Agent 列表，并把 API Agent 提交写入 Mock 评测记录。关闭后，提交页使用真实 Agent 列表、评测校验和评测创建接口。
