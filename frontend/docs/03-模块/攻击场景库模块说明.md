# 攻击场景库模块说明

本文档说明 `src/modules/attack-scenario-library/` 的目录、详情、适配层、目录 Store 和提交流转关系。

## 1. 模块文件概览

| 文件 | 职责 |
| ---- | ---- |
| `api/attack-scenario-library-api.ts` | 读取攻击场景库目录和评测项详情，封装缓存和错误结构 |
| `api/adapters/attack-scenario-library-adapters.ts` | 把后端返回结构适配成前端领域模型 |
| `model/attack-scenario-catalog-view.ts` | 目录页面的攻击场景筛选、风险域筛选、搜索、排序与视图模型构建 |
| `stores/attackScenarioCatalogStore.ts` | 维护目录状态、详情缓存与错误状态 |
| `pages/AttackScenarioCatalogPage.vue` | 攻击场景库页面 |
| `pages/EvaluationItemDetailPage.vue` | 评测项详情页 |

## 2. 页面路由

- `/:locale/attack-scenarios`
- `/:locale/attack-scenarios/evaluation-items/:evaluationItemId`

旧 `/dataset` 路由不保留。

## 3. 目录结构

前端展示三级目录：

```text
攻击场景 -> 风险域 -> 评测项
```

样本只作为聚合数量和详情分布展示，不在目录页展开。

## 4. 提交流转

从目录页或详情页点击评测项时，跳转到提交页并携带：

```text
attackScenarioId
evaluationItemIds
```

提交页会先选中攻击场景，再只允许选择该攻击场景下的评测项。切换攻击场景会清空已选评测项和展开状态。
