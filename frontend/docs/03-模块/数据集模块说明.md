# 数据集模块说明

本文档说明 `src/modules/dataset/` 的目录、详情、适配层、目录 Store 和提交流转关系。

## 1. 模块文件概览

### 1.1 API 与模型层

| 文件                               | 职责                                                                |
| ---------------------------------- | ------------------------------------------------------------------- |
| `api/dataset-api.ts`               | 对外暴露目录 / 详情读取，封装真实 API、缓存和错误结构               |
| `api/adapters/dataset-adapters.ts` | 把后端返回结构适配成前端领域模型；也负责提交 payload 的部分字段适配 |
| `model/dataset-catalog-view.ts`    | 目录页面的搜索、排序与视图模型构建                                  |

### 1.2 页面与状态

| 文件                            | 类型  | 职责                                             |
| ------------------------------- | ----- | ------------------------------------------------ |
| `pages/DatasetCatalogPage.vue`  | 页面  | 数据集目录页，负责加载目录、筛选、排序和分类展示 |
| `pages/DatasetDetailPage.vue`   | 页面  | 数据集详情页，负责加载详情、展示说明、跳转提交页 |
| `stores/datasetCatalogStore.ts` | Store | 维护目录状态、当前分类、详情缓存与错误状态       |

### 1.3 组件与工具

| 文件                                    | 职责                                                 |
| --------------------------------------- | ---------------------------------------------------- |
| `components/DatasetAssetsSection.vue`   | 渲染详情页资源与媒体资产入口                         |
| `components/DatasetMediaGallery.vue`    | 渲染详情页媒体画廊                                   |
| `components/DatasetResourcesList.vue`   | 渲染详情页资源链接                                   |
| `lib/dataset-utils.ts`                  | 分类过滤、数据集 ID 聚合、详情辅助、提交选择相关工具 |
| `lib/dataset-display-utils.ts`          | 数据集展示名称相关工具                               |

## 2. dataset-api 的职责

`src/modules/dataset/api/dataset-api.ts` 是数据集模块的服务门面。

### 2.1 `getDatasetCatalog(options)`

职责：

- 调用真实接口 `/datasets/catalog`
- 把返回值交给 `adaptDatasetCatalog()`
- 在非 `signal` 模式下使用 `withMemoryCache()` 做缓存和并发去重

### 2.2 `getDatasetDetail(datasetId, options)`

职责：

- 调用真实接口 `/datasets/:datasetId`
- 结果交给 `adaptDatasetDetail()`
- 以每个数据集详情为粒度做缓存

### 2.3 错误语义

数据集模块自定义了 `DatasetServiceError`，并保留业务 `code`。

这样上层可以区分：

- 一般加载失败
- `40400` 对应的“评测项不存在”

## 3. DatasetCatalogStore 逻辑

`src/modules/dataset/stores/datasetCatalogStore.ts` 是目录页和详情页共享的状态中心。

### 3.1 关键状态

- `categories`
  数据集分类列表
- `activeCategoryId`
  当前激活的分类
- `loading`、`loaded`、`error`
  目录加载状态
- `detailCache`
  已加载过的数据集详情缓存

### 3.2 关键方法

- `fetchCatalog(force)`
  拉取目录，更新目录版本、分类列表和当前激活分类
- `setActiveCategory(categoryId)`
  切换目录当前分类
- `fetchDatasetDetailById(datasetId, force)`
  拉取详情；若缓存命中且不强制刷新，则直接返回缓存
- `getDatasetSummaryById(datasetId)`
  从目录摘要里反查单个数据集

### 3.3 为什么目录页和详情页共用一个 Store

因为这两类页面都依赖同一份目录数据：

- 目录页直接展示分类和摘要
- 详情页除详情本身外，也经常需要目录中的摘要信息和数据集列表上下文

## 4. 目录页与详情页

### 4.1 DatasetCatalogPage

目录页的核心链路是：

1. 调用 `datasetCatalogStore.fetchCatalog()`
2. 从 Store 中取分类列表
3. 把某个分类交给 `buildDatasetCatalogView(category, search, sortKey)`
4. 由 `DatasetCatalogPage.vue` 内部筛选控件、分类导航和结果卡片完成渲染

`dataset-catalog-view.ts` 当前支持：

- 搜索：匹配数据集名称与短描述
- 排序：
  - 默认顺序
  - 按更新时间倒序
  - 按样本数倒序

### 4.2 DatasetDetailPage

详情页的核心逻辑集中在两件事：

- 根据路由参数拉取详情
- 从详情页直接跳到提交页，并把当前数据集 ID 写入 query

`handleSubmitClick()` 的行为是：

- 未登录：直接打开登录弹窗
- 已登录：跳转到 `RouteLocation.agentSubmit`，并附带 `query.datasetIds = detail.datasetId`

这条 query 会在提交页被解析并转成默认选中的数据集。

## 5. 数据集模块的关键工具

`src/modules/dataset/lib/dataset-utils.ts` 是提交链和目录链之间的重要桥梁。

其典型职责包括：

- `getEnabledCategories()`
  过滤启用中的分类
- `getAllDatasetIds()`
  聚合目录里所有合法数据集 ID
- `findDatasetSummary()`
  根据 ID 从目录中找摘要
- `sanitizeDatasetSelection()`
  清洗提交页已选数据集
- `toggleCategoryDatasets()` / `toggleDatasetId()`
  实现提交页的数据集勾选切换逻辑

这也是数据集模块不只是“展示模块”的原因。它同时向提交模块输出一套稳定的数据选择规则。
