# 智能体模块说明

本文档说明 `src/modules/agent/` 如何管理 Agent 注册、详情、验证、归档、复制新建和 Mock 数据。

## 1. 模块结构

| 路径 | 职责 |
| --- | --- |
| `pages/AgentManagementPage.vue` | Agent 列表、状态展示和常用操作 |
| `pages/AgentRegisterPage.vue` | 模板选择、注册表单、调用预览和创建结果 |
| `pages/AgentDetailPage.vue` | 非敏感配置、验证结果和操作区 |
| `api/agent-api.ts` | Agent API 门面，按 Mock 开关分流 |
| `api/internal/live-agent-api.ts` | 真实 Agent 接口请求 |
| `api/internal/mock-agent-api.ts` | 前端 Mock Agent 接口 |
| `api/internal/mock-agent-store.ts` | Mock Agent 模板、种子数据和本地持久化 |
| `model/agent-registration.ts` | 注册表单初始化、复制预填、payload 校验和调用预览 |
| `model/agent-display.ts` | 状态、调用模式和操作文案 |
| `components/AgentStatusTag.vue` | Agent 状态标签 |

类型集中在 `src/shared/types/agent-registry-types.ts`。

## 2. API 分流

页面只调用 `agent-api.ts`：

```text
getAgentTemplates()
createAgent(payload)
getAgents({ includeArchived })
getAgentDetail(agentId)
verifyAgent(agentId)
archiveAgent(agentId)
```

当 `VITE_ENABLE_API_MOCK=true` 时，上述方法走 `mock-agent-api.ts`；否则走后端 `/api/v1/agents*` 接口。

Mock Agent 数据保存在：

```text
localStorage["agent-platform:mock-agents:v1"]
```

删除该键后会重新写入默认种子数据。

## 3. 注册与复制新建

注册页初始化顺序：

1. 读取 Agent 模板
2. 若 URL 有 `copyFrom=<agentId>`，读取 Agent 详情并预填
3. 否则选择推荐模板并预填表单

复制新建只复用非敏感配置：

- 名称自动追加“副本”
- 连接、映射、自定义字段、状态集合会复制
- Bearer Token、API Key、Header Secret 会清空

创建时调用 `buildAgentCreatePayload()` 做前端校验。校验内容包括名称、连接地址、轮询路径、任务字段映射、自定义字段冲突、输出映射、终态和成功态关系、鉴权凭据。

## 4. 状态与操作

Agent 状态：

```text
draft / verifying / active / invalid / archived
```

页面操作遵循：

- `active` 可提交评测
- `draft`、`active`、`invalid` 可验证
- `draft`、`active`、`invalid` 可归档
- 所有状态都可复制新建
- `archived` 不可验证、归档或提交评测

提交评测入口会跳转到：

```text
/user/submit?agentId=<agentId>
```

提交页会预选该 Agent；只有 `active` 状态允许正式提交。
