# 智能体模块说明

本文档说明 `src/modules/agent/` 如何管理 Agent 注册、详情、验证、归档、复制新建和 Mock 数据。

## 1. 模块结构

| 路径                               | 职责                                             |
| ---------------------------------- | ------------------------------------------------ |
| `pages/AgentManagementPage.vue`    | Agent 列表、状态展示和常用操作                   |
| `pages/AgentRegisterPage.vue`      | 模板选择、注册表单、代码预览和创建结果           |
| `pages/AgentDetailPage.vue`        | 状态摘要、非敏感配置、映射对照、验证结果和操作区 |
| `api/agent-api.ts`                 | Agent API 门面，按 Mock 开关分流                 |
| `api/internal/live-agent-api.ts`   | 真实 Agent 接口请求                              |
| `api/internal/mock-agent-api.ts`   | 前端 Mock Agent 接口                             |
| `api/internal/mock-agent-store.ts` | Mock Agent 模板、种子数据和本地持久化            |
| `model/agent-registration.ts`      | 注册表单初始化、复制预填、payload 校验和调用预览 |
| `model/agent-display.ts`           | 状态、调用模式和操作文案                         |
| `components/AgentStatusTag.vue`    | Agent 状态标签                                   |
| `components/AgentCodePreview.vue`  | curl、Python、JSON 代码预览                      |

类型集中在 `src/shared/types/agent-registry-types.ts`。

## 2. 核心架构设计

Agent 在创建时形成为一份单层配置快照。该配置（包含 `invokeMode`, `connection`, `auth`, `platformInputMapping`, `customRequestBody`, `platformOutputMapping` 等）一旦提交即冻结并不可原地修改，以保证后续发起评测（Evaluation）时数据的可追溯性。任何配置的变更都必须通过“复制新建”生成新的一份 Agent 实例。

## 3. API 分流

页面只调用 `agent-api.ts`：

```text
getAgentTemplates()
createAgent(payload)
getAgents({ includeArchived })
getAgentDetail(agentId)
verifyAgent(agentId)
archiveAgent(agentId)
```

当 `VITE_ENABLE_API_MOCK=true` 时，上述方法走 `mock-agent-api.ts`；否则走后端 `/api/v1/agents*` 接口。

真实后端模式下，验证会调用：

```text
POST /agents/{agentId}/verify
```

请求体包含 `timeoutSeconds`。Mock 模式下，同一门面方法只更新本地 Mock Agent 状态，不请求后端。

Mock Agent 数据保存在：

```text
localStorage["agent-platform:mock-agents:v1"]
```

删除该键后会重新写入默认种子数据。

## 3. 注册与复制新建

注册页初始化顺序：

1. 读取 Agent 模板
2. 若 URL 有 `copyFrom=<agentId>`，读取 Agent 详情并预填
3. 否则选择推荐模板并预填表单

复制新建只复用非敏感配置：

- 名称自动追加“副本”
- 连接、映射、自定义字段、状态集合会复制
- Bearer Token、API Key、Header Secret 会清空

创建时调用 `buildAgentCreatePayload()` 做前端校验。校验内容包括名称、连接地址、轮询路径、任务字段映射、自定义字段冲突（即 `customRequestBody` 的顶层字段名绝不能与 `platformInputMapping` 映射出的外部字段名冲突）、输出映射、终态和成功态关系、鉴权凭据。

注册页右侧代码预览支持：

- curl 调用示例
- Python 调用示例
- 请求体 JSON

代码预览由 `AgentCodePreview.vue` 负责渲染，页面只传入代码内容和语言类型。

## 4. 详情页展示

详情页展示非敏感配置，不展示 secret 明文。主要信息包括：

- 状态摘要、连接配置、鉴权摘要
- 输入字段映射和输出字段映射
- 自定义固定字段
- 状态集合和最近一次验证结果

输入字段映射展示为“平台字段 → Agent 字段”。输出字段映射展示为“响应路径 → 平台字段”，页面使用对照节点展示两端字段关系。

最近一次验证结果展示验证状态、验证时间、错误数量、警告数量，并按错误和警告分组展示表格明细。

## 5. 状态与操作

Agent 状态：

```text
draft / verifying / active / invalid / archived
```

页面操作遵循：

- `active` 可提交评测
- `draft`、`active`、`invalid` 可验证
- `draft`、`active`、`invalid` 可归档
- 所有状态都可复制新建
- `archived` 不可验证、归档或提交评测

管理页默认不显示已归档 Agent；“显示已归档”开关始终保留，即使当前列表为空也可切换查看归档记录。

提交评测入口会跳转到：

```text
/user/submit?agentId=<agentId>
```

提交页会预选该 Agent；只有 `active` 状态允许正式提交。
