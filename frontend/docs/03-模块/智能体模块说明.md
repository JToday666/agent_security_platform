# 智能体模块说明

本文档说明 `src/modules/agent/` 如何管理 Agent 注册、详情、验证、归档和复制新建。

## 2. 核心架构设计

Agent 在创建时形成为一份单层配置快照。该配置（包含 `invokeMode`, `connection`, `auth`, `platformInputMapping`, `customRequestBody`, `platformOutputMapping` 等）一旦提交即冻结并不可原地修改，以保证后续发起评测（Evaluation）时数据的可追溯性。任何配置的变更都必须通过“复制新建”生成新的一份 Agent 实例。

## 3. API 门面

页面只调用 `agent-api.ts`：

```text
getAgentTemplates()
createAgent(payload)
getAgents({ includeArchived })
getAgentDetail(agentId)
verifyAgent(agentId)
archiveAgent(agentId)
```

上述方法当前均走后端 `/api/v1/agents*` 接口；`VITE_ENABLE_API_MOCK` 不接管 Agent 模板、注册、列表、详情、验证和归档链路。

真实后端模式下，验证会调用：

```text
POST /agents/{agentId}/verify
```

请求体包含 `timeoutSeconds`。

## 4. 注册与复制新建

注册页初始化顺序：

1. 读取 Agent 模板
2. 若 URL 有 `copyFrom=<agentId>`，读取 Agent 详情并预填
3. 否则创建空白自定义表单，用户可在模板步骤中手动选择推荐模板或其它模板

复制新建只复用非敏感配置：

- 名称自动追加“副本”
- 最大并发数、连接、取消接口、映射、自定义字段、状态集合会复制
- Bearer Token、API Key、Header Secret 会清空

注册页的状态和动作由 `useAgentRegisterPage.ts` 维护。页面容器只传递表单、错误、预览、创建结果和按钮事件。

创建时调用 `buildAgentCreatePayload()` 做前端校验。校验内容包括名称、必填且取值 1-100 的最大并发数、连接地址、轮询路径、取消路径、任务字段映射、自定义字段冲突（即 `customRequestBody` 的顶层字段名绝不能与 `platformInputMapping` 映射出的外部字段名冲突）、输出映射、终态和成功态关系、鉴权凭据。

注册页右侧代码预览支持：

- curl 调用示例
- Python 调用示例
- 请求体 JSON

调用预览由 `buildAgentInvocationPreview()` 生成，`AgentInvocationPreviewPanel.vue` 负责展示，`AgentCodePreview.vue` 负责渲染具体代码块。

## 5. 详情页展示

详情页的加载、验证、归档和复制入口由 `useAgentDetailPage.ts` 维护。页面容器只拼装展示组件和确认弹窗。

详情页展示非敏感配置，不展示 secret 明文。主要信息包括：

- 状态摘要、连接配置、鉴权摘要
- 输入字段映射和输出字段映射
- 自定义固定字段
- 状态集合和最近一次验证结果

输入字段映射展示为“平台字段 -> Agent 字段”。输出字段映射展示为“响应路径 -> 平台字段”，页面使用对照节点展示两端字段关系。

`agent-detail-view.ts` 负责把详情字段派生为摘要项、连接项、鉴权项、映射行、状态集合和验证消息分组。最近一次验证结果展示验证状态、验证时间、错误数量、警告数量，并按错误和警告分组展示表格明细。

## 6. 状态与操作

Agent 状态：

```text
draft / verifying / active / invalid / archived
```

页面按钮以接口返回的 `canVerify`、`canArchive` 和 `canSubmitEvaluation` 为准；当前状态规则遵循：

- `active` 可提交评测
- `draft`、`active`、`invalid` 可验证
- `draft`、`active`、`invalid` 可归档
- 所有状态都可复制新建
- `archived` 不可验证、归档或提交评测

管理页默认不显示已归档 Agent；“显示已归档”开关始终保留，即使当前列表为空也可切换查看归档记录。

提交评测入口会跳转到：

```text
/:locale/user/submit?agentId=<agentId>
```

提交页会预选该 Agent；只有 `active` 且 `canSubmitEvaluation=true` 的 Agent 允许正式提交。
