# 前端架构说明

本文档从宏观视角说明前端工程的分层、目录职责、页面入口和阅读顺序。

## 1. 总体分层

前端代码围绕三层展开：

- `src/app/`
  应用壳层。负责把应用跑起来，并决定页面外围的路由、布局、导航和全局样式体系
- `src/modules/`
  业务模块层。负责账号、Agent、数据集、提交评测、评测记录与详情、公共页面等具体业务
- `src/shared/`
  共享基础设施层。负责 API 基础封装、共享类型、运行时工具、共享 UI 组件和静态资源

基本原则：

- `app` 不直接承载具体业务规则，主要承载应用框架
- `modules` 负责业务域内的页面、状态、组合逻辑和服务层
- `shared` 只放真正跨模块复用的能力，不承载单一业务域的私有实现

## 2. 目录与职责

### 2.1 app 层

`src/app/` 目前主要分为四部分：

- `layouts/`
  页面外壳。`PublicLayout.vue` 承载公共页面，`UserLayout.vue` 承载登录后的工作台页面，并把 sticky 侧边栏与主内容区组织为双列布局
- `router/`
  路由定义与守卫。负责路由树、命名路由对象、鉴权守卫、滚动恢复
- `shell/`
  导航外壳。负责顶部导航、工作台侧边栏、导航项配置、壳层上下文判断
- `styles/`
  全局 SCSS 设计体系。由 `main.scss` 串联 tokens、primitives、semantic、layout、utilities

### 2.2 modules 层

`src/modules/` 当前分为六个业务域：

- `account`
  登录弹窗、用户资料页、用户 Store
- `agent`
  Agent 管理、注册、详情、验证、归档、复制新建和 Mock 数据
- `dataset`
  数据集目录、详情、数据适配、目录 Store、目录视图与数据集工具
- `evaluation`
  提交元数据、评测记录、详情、任务动作、live/mock 分流、状态规则
- `public`
  首页、联系我们、排行榜、404
- `submission`
  提交页表单、参数校验、提交草稿、数据集选择、预检查和正式提交

### 2.3 shared 层

`src/shared/` 当前主要包含：

- `api/`
  API 配置、Axios 基础封装、运行时 URL 工具、内存缓存、Mock 辅助
- `assets/`
  共享静态资源
- `constants/`
  本地存储键等常量
- `lib/`
  通用工具，如滚动状态保存、资源地址 cache bust
- `types/`
  跨模块复用的业务类型与通用响应类型
- `ui/`
  共享 UI 组件，按动作、展示、反馈、表单、页面容器等分类

## 3. 页面入口与布局关系

前端页面由路由树驱动：

- 公共页面走 `PublicLayout.vue`
  首页、数据集目录、数据集详情、排行榜、联系页、404
- 工作台页面走 `UserLayout.vue`
  评测记录、评测详情、提交评测、个人资料

根组件与入口关系如下：

```text
index.html
-> src/main.ts
-> src/App.vue
-> router-view
-> PublicLayout.vue / UserLayout.vue
-> 各模块页面组件
```

`src/App.vue` 本身只负责两件事：

- 提供 `<router-view />` 作为页面出口
- 全局挂载 `LoginDialog.vue`，保证任意页面都能统一唤起登录

## 4. 前端侧数据流

前端业务代码的典型数据流如下：

```text
页面 / 共享组件
-> composable 或 store
-> 模块 api 门面
-> live / mock 实现
-> adapter / sanitize
-> shared/api/http-client.ts
-> 后端或本地 Mock
```

不同层关注点不同：

- 页面层负责展示、交互和调用入口
- composable / store 负责状态管理与页面编排
- 模块 api 层负责对外暴露稳定的业务接口
- adapter / sanitize 负责把后端结构适配成前端领域模型
- `http-client.ts` 负责鉴权头、统一响应封装、错误提取和 401 事件派发

## 5. 当前共享 UI 基线

当前页面级共享 UI 已统一收口为：

- `PageHero.vue`
  平铺页面头部容器，支持 `align`、`descriptionWrap`、前缀区和动作区
- `SectionBlock.vue`
  内容分区容器，支持 `surface="line" | "panel"`
- `PageStatePanel.vue`
  页面级加载、空态、失败态容器
- `MetricStat.vue`
  详情与摘要区的指标卡
- `UiSelect.vue`
  下拉交互基线，供 `FormField` 的 `type="select"` 模式内部使用

旧的页面级共享组件命名已不再作为当前架构的一部分。

## 6. 当前验证基线

当前仓内不保留 `frontend/src` 下测试源码，但保留测试工具链用于后续调试和补充验证。

前端日常验证以以下方式为主：

- `pnpm type-check`
- `pnpm build`
- 受影响页面的定向手工走查

## 7. 推荐阅读顺序

第一次接手这个前端时，推荐按下列顺序阅读：

1. `frontend/README.md`
   先确认运行命令、环境变量与文档入口
2. `src/main.ts`、`src/App.vue`
   理解应用入口、登录恢复和全局未授权处理
3. `src/app/router/`、`src/app/layouts/`、`src/app/shell/`
   理解页面怎么挂到布局里，以及导航如何工作
4. 对应业务模块的 `pages / composables / stores / api`
   按“页面 -> 编排逻辑 -> 服务层 -> 适配层”的顺序读
5. `src/shared/api/`、`src/shared/types/`、`src/shared/ui/`
   补齐底层封装、类型和共享 UI 能力
