# 文档地图

本文档定义 `frontend/` 文档体系的入口、阅读顺序和维护边界。

## 1. 入口约定

- `frontend/README.md`
  前端项目入口，只写当前状态、运行方式、命名规范、文档索引
- `frontend/docs/`
  前端内部结构说明、模块说明、链路说明、文档维护规则
- `share/`
  跨端接口契约主文档；前端文档只解释前端如何消费和处理这些契约

## 3. 遇到问题先看哪里

- 想快速启动前端：看 [README.md](../../README.md)
- 想先理解代码分层和阅读顺序：看 [前端架构说明](./前端架构说明.md)
- 想理解入口启动、未授权处理、Mock 开关、运行时配置：看 [应用启动与运行时说明](../02-架构/应用启动与运行时说明.md)
- 想理解布局、路由、导航和滚动恢复：看 [路由布局与导航说明](../02-架构/路由布局与导航说明.md)
- 想理解前端国际化目录、接入边界和后续策略：看 [国际化架构说明](../02-架构/国际化架构说明.md)
- 想理解登录、资料、回跳：看 [账号与鉴权模块说明](../03-模块/账号与鉴权模块说明.md)
- 想理解 Agent 管理、注册、验证和复制新建：看 [智能体模块说明](../03-模块/智能体模块说明.md)
- 想理解数据集目录和详情：看 [数据集模块说明](../03-模块/数据集模块说明.md)
- 想理解提交页编排和校验：看 [提交评测模块说明](../03-模块/提交评测模块说明.md)
- 想理解评测记录、趋势、详情、报告阅读流和任务动作：看 [评测模块说明](../03-模块/评测模块说明.md)
- 想按调用链理解整个系统：看 [关键链路说明](../04-流程/关键链路说明.md)
- 想调整页面、表单、表格或导航的视觉与交互：看 [前端 UI 设计规范](../05-规范/前端UI设计规范.md)
- 想判断某段说明该写在哪：看 [文档维护约定](../05-规范/文档维护约定.md)

## 4. 主维护边界

- 前端运行命令、环境变量、命名规范和文档索引主维护在 `frontend/README.md`
- 前端分层、模块职责、前端侧状态流与调用链主维护在 `frontend/docs/`
- 跨端接口路径、字段语义、请求响应包裹、补充契约和国际化总策略主维护在 `share/`
