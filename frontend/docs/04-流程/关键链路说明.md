# 关键链路说明

本文档不按目录看代码，而是按业务链路串联前端的关键调用关系。

## 1. 启动链

```text
index.html
-> src/main.ts
-> createPinia()
-> useUserStore(pinia)
-> 注册 unauthorized 监听
-> userStore.restoreLogin()（不阻塞启动）
-> app.use(router)
-> src/App.vue
-> router-view
-> PublicLayout.vue / UserLayout.vue
-> 对应页面组件
```

要点：

- 登录恢复在启动时后台进行，公共页面可以先完成首屏渲染；受保护路由在守卫里按需等待 `initPromise`
- 登录弹窗全局挂载，不依赖具体页面

## 2. 401 未授权处理链

```text
真实 API 请求
-> src/shared/api/http-client.ts 响应拦截器收到 401
-> window.dispatchEvent("unauthorized")
-> src/main.ts 监听器
-> userStore.setPostLoginRedirect(currentRoute.fullPath)
-> userStore.logout()
-> userStore.openLoginDialog()
-> router.push(RouteLocation.home)
```

## 3. 路由鉴权链

```text
用户访问 /:locale/user/*
-> route-guards.ts
-> 检查 meta.requiresAuth
-> useUserStore().isLogin
-> 未登录时记录 postLoginRedirect
-> 打开 LoginDialog
-> 回首页
```

## 6. 排行榜链

```text
LeaderboardPage.vue
-> useLeaderboardPage.loadLeaderboard()

-> adaptLeaderboardSnapshot()
-> leaderboard-view.ts 排序、分数格式化和奖牌色调
```

## 8. 提交评测链

```text
用户点击提交
-> useSubmitAgentPage.handleSubmit()
-> buildSubmitPayloadSnapshot()
-> buildSubmitPayloadFromSnapshot()
-> payload.attackScenarioId + payload.evaluationItemIds
-> payload.leaderboardDisplayMode 标记公开或匿名
-> validateSubmitPayload(payload, meta, validEvaluationItemIds, activeAgentIds)
-> precheckAgent(payload)
-> ConfirmDialog
-> confirmSubmit()
-> submitAgent(confirmedPayload)
-> submitDraftStore.clearDraftAfterSubmit()
-> router.push(RouteLocation.evaluationDetail(evaluationId))
```

API 模式下，payload 使用已注册 Agent 的 `agentId`。Docker 模式显示不可提交提示，不进入预检查和正式提交。

## 13. 评分报告链

```text
EvaluationDetailPage.vue
-> useEvaluationDetailPage.loadReport()
-> getEvaluationReport(evaluationId)
-> adaptEvaluationReportPayload()
-> EvaluationReportSection.vue
-> evaluation-report-metrics.ts 派生能力结构、结果率和置信区间
-> evaluation-report-insights.ts 派生摘要、难度桶说明和数据集说明
-> evaluation-report-chart-options.ts 构造图表 option
-> components/charts/*.vue 渲染 ECharts
```

详情接口先驱动状态、进度、样本统计和基础信息。报告接口只驱动评分报告区；报告不可用或加载失败时，详情页其它信息保持可读。

报告区按结论概览、能力结构、样本结果、风险归因和样本定位组织。能力结构表与雷达图使用同一组 6 维指标；样本结果区并列展示三态数量结构和结果率；置信区间条展示后验分数范围。

报告不存在或加载失败时，报告区由前端适配层或空态降级承接，但页面其余区域保持可读。

难度桶组合图和数据集结果图支持悬停预览与点击锁定：

```text
ReportDifficultyBarChart.vue / ReportDatasetStackedBarChart.vue
-> emit preview / select
-> EvaluationReportSection.vue 保存局部选择
-> resolveDifficultyBucketInsight() / resolveDatasetSummaryInsight()
-> 更新图表旁说明
```

## 14. 代表样本与下载链

```text
EvaluationDetailPage.vue
-> EvaluationEvidenceSection.vue
-> selectRepresentativeSamples()
-> 展示成功样本和失败/异常样本
```

样本明细下载链：

```text
用户点击下载样本明细
-> downloadSampleDetails()
-> 读取 detail.downloads.sampleDetailsUrl
-> downloadEvaluationSampleDetails(sampleDetailsUrl)
-> 下载成功时由浏览器处理文件
-> 下载失败时在证据区显示局部失败提示
```

当前后端未提供独立样本导出接口时，报告 payload 不会返回样本明细下载地址；该入口保持不可用，不影响详情页其它区域。

## 15. 评测动作链

```text
用户点击暂停 / 恢复 / 终止 / 取消
-> openActionDialog(action)
-> ConfirmDialog
-> confirmAction()
-> runAction(action)
-> postEvaluationAction(evaluationId, action)
-> applyDetail(nextDetail)
-> syncPolling()
```

若动作因状态冲突失败：

```text
postEvaluationAction() 返回 40901 / 40902
-> 详情页保留错误信息
-> 再次 loadDetail(true)
-> 用服务端最新状态回正页面
```
