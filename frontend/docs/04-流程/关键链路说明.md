# 关键链路说明

本文档不按目录看代码，而是按业务链路串联前端的关键调用关系。

## 1. 启动链

```text
index.html
-> src/main.ts
-> createPinia()
-> useUserStore(pinia)
-> 注册 unauthorized 监听
-> userStore.restoreLogin()（不阻塞启动）
-> app.use(router)
-> src/App.vue
-> router-view
-> PublicLayout.vue / UserLayout.vue
-> 对应页面组件
```

要点：

- 登录恢复在启动时后台进行，公共页面可以先完成首屏渲染；受保护路由在守卫里按需等待 `initPromise`
- 登录弹窗全局挂载，不依赖具体页面

## 2. 401 未授权处理链

```text
真实 API 请求
-> src/shared/api/http-client.ts 响应拦截器收到 401
-> window.dispatchEvent("unauthorized")
-> src/main.ts 监听器
-> userStore.setPostLoginRedirect(currentRoute.fullPath)
-> userStore.logout()
-> userStore.openLoginDialog()
-> router.push(RouteLocation.home)
```

## 3. 路由鉴权链

```text
用户访问 /user/*
-> route-guards.ts
-> 检查 meta.requiresAuth
-> useUserStore().isLogin
-> 未登录时记录 postLoginRedirect
-> 打开 LoginDialog
-> 回首页
```

## 4. 数据集目录链

```text
DatasetCatalogPage.vue
-> useDatasetCatalogStore().fetchCatalog()
-> getDatasetCatalog()
-> live API 或 Mock 数据
-> adaptDatasetCatalog()
-> DatasetCatalogStore.categories
-> buildDatasetCatalogView(category, search, sortKey)
-> DatasetFilterBar.vue / DatasetCategorySection.vue / DatasetSubcategoryCard.vue
```

## 5. 数据集详情到提交页链

```text
DatasetDetailPage.vue
-> handleSubmitClick()
-> 未登录: userStore.openLoginDialog()
-> 已登录: router.push(RouteLocation.agentSubmit, query.datasetIds=detail.datasetId)
-> SubmitAgentPage.vue
-> useSubmitAgentPage.applyDatasetQuerySelection()
-> resolveDatasetIdsFromQuery()
-> 当前表单选中该数据集
```

## 6. 提交页初始化链

```text
SubmitAgentPage.vue
-> useSubmitAgentPage.initializePage()
-> getSubmitMeta()
-> submitDraftStore.applyMeta(meta)
-> loadCatalog(true)
-> useSubmitDatasetCatalog.fetchCatalog()
-> submitDraftStore.syncWithCatalog(categories)
-> applyDatasetQuerySelection()
```

## 7. 提交评测链

```text
用户点击提交
-> useSubmitAgentPage.handleSubmit()
-> buildPayload("submit")
-> validateSubmitPayload()
-> precheckAgent(payload)
-> ConfirmDialog
-> confirmSubmit()
-> submitAgent(confirmedPayload)
-> submitDraftStore.clearDraftAfterSubmit()
-> router.push(RouteLocation.evaluationDetail(evaluationId))
```

## 8. 评测记录链

```text
EvaluationRecordsPage.vue
-> loadRecords()
-> getEvaluationRecords()
-> evaluation-api.ts 分流到 live / mock
-> adapt + sanitize
-> filterEvaluationRecords()
-> EvaluationRecordItem.vue
```

## 9. 评测详情与轮询链

```text
EvaluationDetailPage.vue
-> useEvaluationDetailPage.loadDetail()
-> getEvaluationDetail(evaluationId)
-> syncPolling()
-> shouldPollEvaluation(status)
-> 需要轮询时 setInterval 每 10 秒刷新
```

## 10. 评测动作链

```text
用户点击暂停 / 恢复 / 终止 / 取消
-> openActionDialog(action)
-> ConfirmDialog
-> confirmAction()
-> runAction(action)
-> postEvaluationAction(evaluationId, action)
-> applyDetail(nextDetail)
-> syncPolling()
```

若动作因状态冲突失败：

```text
postEvaluationAction() 返回 40901 / 40902
-> 详情页保留错误信息
-> 再次 loadDetail(true)
-> 用服务端最新状态回正页面
```

## 11. 导航上下文链

```text
当前 route.name
-> shell-context.ts
-> resolveShellContext()
-> NavBarShell.vue 决定显示公共导航还是工作台导航
-> UserSidebarShell.vue 仅在 UserLayout 中渲染
```

## 12. 样式加载链

```text
src/main.ts
-> import "./app/styles/main.scss"
-> tokens.scss
-> primitives.scss
-> semantic.scss
-> layout-shared.scss
-> utilities.scss
-> 页面与共享 UI 局部样式
```
