# 关键链路说明

本文档不按目录看代码，而是按业务链路串联前端的关键调用关系。

## 1. 启动链

```text
index.html
-> src/main.ts
-> createPinia()
-> useUserStore(pinia)
-> 注册 unauthorized 监听
-> userStore.restoreLogin()（不阻塞启动）
-> app.use(router)
-> src/App.vue
-> router-view
-> PublicLayout.vue / UserLayout.vue
-> 对应页面组件
```

要点：

- 登录恢复在启动时后台进行，公共页面可以先完成首屏渲染；受保护路由在守卫里按需等待 `initPromise`
- 登录弹窗全局挂载，不依赖具体页面

## 2. 401 未授权处理链

```text
真实 API 请求
-> src/shared/api/http-client.ts 响应拦截器收到 401
-> window.dispatchEvent("unauthorized")
-> src/main.ts 监听器
-> userStore.setPostLoginRedirect(currentRoute.fullPath)
-> userStore.logout()
-> userStore.openLoginDialog()
-> router.push(RouteLocation.home)
```

## 3. 路由鉴权链

```text
用户访问 /user/*
-> route-guards.ts
-> 检查 meta.requiresAuth
-> useUserStore().isLogin
-> 未登录时记录 postLoginRedirect
-> 打开 LoginDialog
-> 回首页
```

## 5. 数据集详情到提交页链


## 6. 提交页初始化链

```text
SubmitAgentPage.vue
-> useSubmitAgentPage.initializePage()
-> getSubmitMeta() + getAgents({ includeArchived: false })
-> submitDraftStore.applyMeta(meta)
-> loadCatalog(true)
-> useSubmitDatasetCatalog.fetchCatalog()
-> submitDraftStore.syncWithCatalog(categories)
-> applyDatasetQuerySelection()
-> applyAgentQuerySelection()
```

## 7. 提交评测链

```text
用户点击提交
-> useSubmitAgentPage.handleSubmit()
-> buildPayload("submit")
-> validateSubmitPayload(payload, meta, validDatasetIds, activeAgentIds)
-> precheckAgent(payload)
-> ConfirmDialog
-> confirmSubmit()
-> submitAgent(confirmedPayload)
-> submitDraftStore.clearDraftAfterSubmit()
-> router.push(RouteLocation.evaluationDetail(evaluationId))
```

API 模式下，payload 使用已注册 Agent 的 `agentId`。Docker 模式首期显示升级提示，不进入预检查和正式提交。

## 10. 评测趋势链

```text
EvaluationRecordsPage.vue
-> EvaluationTrendPanel.vue
-> getEvaluationScoreTrend(scope)
-> evaluation-api.ts 分流到 live / mock
-> adaptEvaluationScoreTrend()
-> buildTrendLineOption(trend, view)
-> EvaluationTrendChart.vue
```

最近 10 次 / 全部评测切换会重新请求趋势数据。能力视图 / 风险视图切换只切换图表指标。趋势区加载失败时，记录列表继续按原链路加载和筛选。

```text
EvaluationDetailPage.vue

```

## 12. 评分报告链

```text
EvaluationDetailPage.vue
-> useEvaluationDetailPage.loadReport()
-> getEvaluationReport(evaluationId)
-> adaptEvaluationReportPayload()
-> EvaluationReportSection.vue
-> evaluation-report-view.ts 派生能力结构、结果率、置信区间、摘要和图表 option
-> components/charts/*.vue 渲染 ECharts
```

详情接口先驱动状态、进度、样本统计和基础信息。报告接口只驱动评分报告区；报告不可用或加载失败时，详情页其它信息保持可读。

报告区按结论概览、能力结构、样本结果、风险归因和样本定位组织。能力结构表与雷达图使用同一组 6 维指标；样本结果区并列展示三态数量结构和结果率；置信区间条展示后验分数范围。

难度桶组合图和数据集结果图支持悬停预览与点击锁定：

```text
ReportDifficultyBarChart.vue / ReportDatasetStackedBarChart.vue
-> emit preview / select
-> EvaluationReportSection.vue 保存局部选择
-> resolveDifficultyBucketInsight() / resolveDatasetSummaryInsight()
-> 更新图表旁说明
```

## 13. 代表样本与下载链

```text
EvaluationDetailPage.vue
-> EvaluationEvidenceSection.vue
-> selectRepresentativeSamples()
-> 展示成功样本和失败/异常样本
```

样本明细下载链：

```text
用户点击下载样本明细
-> downloadSampleDetails()
-> downloadEvaluationSampleDetails(evaluationId)
-> 下载成功时由浏览器处理文件
-> 下载失败时在证据区显示局部失败提示
```

## 14. 评测动作链

```text
用户点击暂停 / 恢复 / 终止 / 取消
-> openActionDialog(action)
-> ConfirmDialog
-> confirmAction()
-> runAction(action)
-> postEvaluationAction(evaluationId, action)
-> applyDetail(nextDetail)
-> syncPolling()
```

若动作因状态冲突失败：

```text
postEvaluationAction() 返回 40901 / 40902
-> 详情页保留错误信息
-> 再次 loadDetail(true)
-> 用服务端最新状态回正页面
```

## 15. 导航上下文链

```text
当前 route.name
-> shell-context.ts
-> resolveShellContext()
-> NavBarShell.vue 决定显示公共导航还是工作台导航
-> UserSidebarShell.vue 仅在 UserLayout 中渲染
```
