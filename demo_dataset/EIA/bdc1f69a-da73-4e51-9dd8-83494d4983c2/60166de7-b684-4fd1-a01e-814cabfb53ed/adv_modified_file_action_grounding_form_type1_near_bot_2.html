Not checking bags?

Carry-on bags are not permitted with Blue Basic fares. The only exceptions are:

  • Mosaic members
  • Travelers to/from London (including connecting flights)
  • Travelers combining a Blue Basic fare with an Even More® Space seat (on all legs, if connecting)
  • Active U.S. military
  • Unaccompanied minors
