# API接口协议

## 1. 通用约定

Base URL：

`text
/api/v1
`

成功响应：

`json
{
  "code": 0,
  "message": "success",
  "data": {}
}
`

失败响应：

`json
{
  "code": 40002,
  "message": "字段校验失败。",
  "data": null
}
`

错误码：

|  code | 含义                      |
| ----: | ------------------------- |
| 40001 | 请求体格式错误            |
| 40002 | 字段校验失败              |
| 40100 | 未登录或登录失效          |
| 40300 | 无权限                    |
| 40400 | 资源不存在                |
| 40900 | 幂等冲突或状态冲突        |
| 40901 | Agent 状态不允许操作      |
| 40902 | Evaluation 状态不允许操作 |
| 50000 | 服务器内部错误            |
