# 后端国际化待实现清单

## 1. 背景与边界

前端已经在接口请求中发送 `X-App-Locale` 与 `Accept-Language`，后端需要根据请求语言返回后端拥有的展示文案。

后端负责翻译后端生成、维护或持久化的用户可见文案。前端页面标题、按钮、表单标签、空状态、布局提示等前端 UI 文案仍由前端语言包负责。

不纳入后端翻译范围：

- 用户输入内容，例如用户名、Agent 名称、Agent 描述、任务备注。
- 稳定协议字段，例如枚举 code、状态值、ID、路由、请求字段名、响应字段名。
- 外部 Agent 返回的原始错误、响应内容和运行产物原文。
- 代码注释、数据库注释、日志中仅供开发排查的内部文本。

## 2. 待实现内容

### Locale 解析与响应头

- 统一解析 `X-App-Locale`，缺失时解析 `Accept-Language`。
- 支持与前端一致的语言：`zh-CN`、`en-US`、`fr-FR`、`es-ES`、`ja-JP`。
- 支持常见别名归一化，例如 `zh` 到 `zh-CN`、`en` 到 `en-US`。
- 未传语言或不支持的语言默认回退 `zh-CN`。
- 本地化响应增加 `Content-Language`。
- 增加 `Vary: Accept-Language, X-App-Locale`，避免缓存串语言。

### 错误与校验提示

- `DomainError`、`ValidationDomainError`、`AuthError`、`ForbiddenError`、`NotFoundError`、`ConflictError` 的 `message` 按请求语言返回。
- FastAPI 参数校验错误的 `message` 与 `data.errors[].reason` 按请求语言返回。
- HTTPException 与未捕获异常兜底提示按请求语言返回。
- 业务错误保留稳定 `code`，不要用翻译文案作为前端判断条件。

### 数据集目录与详情

- 目录页风险大类字段：`name`、`meaning`、`description`。
- 目录页评测项字段：`name`、`shortDescription`。
- 详情页分类字段：`category.name`、`category.meaning`。
- 详情页评测项字段：`name`、`shortDescription`、`fullDescription`、`highlights`、`scenarios`。
- 详情页资源与媒体字段：资源 `label`，媒体 `title`、`description`。
- 资源 URL、媒体 URL、类型 code 不翻译。

### Agent 相关文案

- 内置 Agent 模板的 `name`、`description`、`tags` 按请求语言返回。
- 后端生成的 Agent 配置校验错误按请求语言返回。
- Agent 验证过程中由后端生成的 warning/error message 按请求语言返回。
- 外部 Agent 原始错误不翻译，可用本地化包装提示说明“外部 Agent 返回错误”，并保留原文。

### 评测相关文案

- 提交预检 `warnings[].message` 按请求语言返回。
- 评测详情 `progress.statusText` 按请求语言返回。
- 评测报告 `summary.byRiskCategory[].name` 按请求语言返回。
- 评测动作失败提示、幂等冲突提示、状态不允许操作提示按请求语言返回。
- 历史评测中的 `datasetNames` 应优先按当前 locale 解析，旧快照名称仅作为 fallback。

### 排行榜、评分与难度

- 排行榜匿名展示名按请求语言返回，例如中文为“匿名 Agent”，英文为“Anonymous Agent”。
- 排行榜不存在、评分不存在、评测未结束、难度版本不存在等错误提示按请求语言返回。
- `verificationTier`、`safetyCertification`、score model version、benchmark version 等稳定值不翻译。

## 3. 接口建议

- 继续保持现有 envelope：`{ code, data, message }`。
- `message` 始终返回当前请求语言下的可展示文案，保证旧前端兼容。
- 可选新增错误字段：
  - `messageKey`：稳定翻译 key。
  - `messageParams`：翻译插值参数。
- 可选新增校验错误字段：
  - `reasonKey`：字段错误翻译 key。
  - `reasonParams`：字段错误插值参数。
- 前端短期仍可只读 `message`；后续可逐步改为优先读 `messageKey/messageParams`。
- 数据 payload 默认返回单语言字段，例如 `name`、`description`；不建议在常规接口返回完整 `nameI18n` 或 `translations` map。
- 若后续需要前端做离线切换，可另建专用元数据导出接口，不影响现有业务接口。

## 4. 翻译保存建议

### 运行时短文案

- 错误、状态、模板、校验提示等短文案放后端语言包。
- 建议目录形态为 `backend/app/platform/i18n/messages/{locale}/*.json`。
- 代码中只引用稳定 key 和参数，不再直接拼接用户可见中文。
- 缺失翻译时回退 `zh-CN`，仍缺失时回退 key 或安全兜底文案。

### 数据集元数据

- `data/metadata` 继续作为数据集元数据 JSON 真源。
- 默认中文字段继续保留为 canonical fallback。
- 在 JSON 记录中新增 `translations` 字段，例如：

```json
{
  "code": "confidentiality",
  "name": "机密性",
  "meaning": "敏感信息保护与最小暴露。",
  "translations": {
    "en-US": {
      "name": "Confidentiality",
      "meaning": "Sensitive information protection with minimal exposure."
    }
  }
}
```

### 数据库存储

- 给 `risk_categories` 增加 `translations JSONB NOT NULL DEFAULT '{}'`。
- 给 `risk_subtypes` 增加 `translations JSONB NOT NULL DEFAULT '{}'`。
- 给 `risk_subtype_display_meta` 增加 `translations JSONB NOT NULL DEFAULT '{}'`。
- 如后续公开数据源、攻击投递方式、资产类型，也给对应表增加同类 `translations` 字段。
- 请求时按 locale 从 `translations` 取值，缺失字段逐级回退到中文原字段。
- 不保存每次请求的翻译结果，避免重复数据和缓存失效问题。

## 5. 实施步骤

1. 新增后端 i18n 基础模块，完成 locale 解析、别名归一化、语言包加载、fallback 和参数插值。
2. 在请求上下文或依赖中提供当前 locale，所有服务层和异常处理器通过统一入口读取。
3. 扩展错误模型，支持 `message_key`、`message_params`，并保持原有 `message` 兼容。
4. 改造全局异常处理器，统一本地化业务异常、HTTPException、FastAPI 参数校验和兜底异常。
5. 替换 auth、user、agents、evaluations、scoring、difficulty、leaderboards、platform 中的硬编码用户可见错误。
6. 增加 Alembic 迁移和 ORM 字段，补齐 `translations JSONB`。
7. 扩展 metadata dataclass、导入脚本和 JSON 真源，使数据集翻译可随导入写入数据库。
8. 改造 datasets catalog/detail 输出，按当前 locale 返回本地化字段。
9. 改造 evaluations 输出，覆盖 precheck warning、progress statusText、datasetNames、report 风险分类名称。
10. 改造 agents 模板与验证结果，模板文案和后端生成提示走语言包。
11. 改造 leaderboard、scoring、difficulty 中的后端展示文案。
12. 补充后端接口文档和错误码约定，说明 locale header、fallback 和兼容字段。

## 6. 验收检查

- 不带语言头时，接口仍默认返回中文。
- 使用 `X-App-Locale: en-US` 时，错误、数据集、评测和模板文案返回英文。
- 使用仅包含 `Accept-Language` 的请求时，后端能正确解析语言。
- 使用不支持语言时，后端回退 `zh-CN`。
- 翻译缺失字段按字段级 fallback 回退中文，不影响接口结构。
- 旧前端只读取 `message` 仍能正常展示错误。
- 数据集 catalog/detail 覆盖分类、评测项、详情、资源和媒体文案。
- 评测 validate warning、detail progress.statusText、report 风险分类名称均支持 locale。
- Agent 模板、Agent 校验错误、Agent 验证提示均支持 locale。
- 排行榜匿名展示名和后端错误提示均支持 locale。
- Alembic 迁移可正向执行，metadata 导入重复执行保持幂等。
- 自动化测试覆盖 locale 解析、错误本地化、数据集本地化和评测本地化。
