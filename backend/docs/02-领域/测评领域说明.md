## 1. 说明范围

## 2. 当前仓库现状

### 已落地

- `backend/data/` 保存原始样本、页面资源和 `agent_runtime` 家族目录
- `backend/dataset_metadata/` 保存版本化元数据和工作簿镜像
- `POST /api/v1/agents/submit`、`GET /api/v1/evaluations`、`GET /api/v1/evaluations/{evaluationId}`、`POST /api/v1/evaluations/{evaluationId}/actions` 已对外开放
- worker 已具备任务认领、心跳续约、暂停/恢复/终止/取消、样本执行和任务级摘要写回能力
- `synthetic_local` 可以闭合 runtime 启动、事件采集、finalize、回放结果生成和基础产物落库

### 仍待补齐

- 真实被测 Agent API 调用
- 真实 Docker 运行链
- 结构化 evaluator / oracle 执行链
- 样本级 execution 查询接口
- `report_uri` 离线报告导出

## 3. 核心领域对象

- 样本：可执行的单个测评单元，包含用户目标、攻击目标、入口资源和 oracle 定义
- 任务：一次用户提交形成的评测 run，负责组织数据集、样本集合、执行配置和汇总结果
- 执行：某个样本在某次任务中的一次实际运行，可为后续重试预留
- oracle：样本定义层的判定规则集合，描述“安全完成”或“违规/受损”
- 报告：任务级聚合产物，用于沉淀统计、结论和证据引用

## 4. 样本运行框架

当前样本运行框架由两部分组成：

- `app/worker/runtime/*`
  - 负责创建 `runtime/workdir/<execution_id>`、分配端口、拉起 probe backend、收集基础产物
- `backend/data/**/agent_runtime/*`
  - 负责样本侧的 `compiler.py / replay.py / backend.py / web/templates/*`
  - worker 会把对应样本目录和 `agent_runtime/` 复制到运行目录，再由 probe backend 调用

因此，`backend/data/**/agent_runtime` 是当前样本运行框架的重要组成，不是无关静态资源目录。

## 5. 任务执行生命周期

当前实现的任务级生命周期如下：

1. 用户提交被测 Agent 的配置或镜像信息
2. 后端预检查提交参数、数据集选择和执行配置
3. 后端创建 `test_runs`、`run_datasets`、`run_samples`、`sample_executions`
4. worker 认领任务并按数据集顺序驱动样本执行
5. runtime 为样本准备工作目录、入口 URL、环境标识，并拉起 probe backend
6. dispatch 触发 `synthetic_local` 或其他适配模式，完成编译/回放和基础证据收集
7. worker 写入 `execution_artifacts`、`execution_summaries`
8. 任务收尾时汇总 `run_reports.summary_json`，详情接口返回任务级快照和摘要

## 6. oracle 与结果语义

在领域层，oracle 只承担“规则定义”职责：

- `success`
  - 描述安全完成条件
- `harm`
  - 描述违规或受损条件

当前实现与目标实现需要拆开理解：

- 当前已落地
  - `sample_oracles` 会在导入阶段入库
  - worker 当前不会逐条执行 `evaluator_type / evaluator_config`
  - 运行结束后只写 `execution_summaries`
- 当前结果语义
  - `synthetic_local` 成功闭环默认写 `final_label = "needs_review"`
  - 超时默认写 `final_label = "timeout"`
  - 这些结果只表示“runtime 闭环和基础证据已完成”，不表示真实安全评分已落地
- 目标能力
  - 逐条生成 `oracle_results`
  - 产出可解释的 `score`、证据引用和稳定分类

## 7. 报告语义

当前 `run_reports` 只承担任务级摘要职责：

- `summary_json`
  - 已落地，包含总样本数、已完成数、任务完成数、损害检出数、按风险/攻击等级聚合等结构化摘要
- `report_uri`
  - 模型已预留，但当前不生产离线文件

因此，当前任务报告是“任务级聚合摘要”，不是完整离线报告导出链路。
