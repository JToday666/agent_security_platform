# 枚举与状态约定

本文档是后端状态值、动作值和稳定 code 的主维护文档。
统一响应包裹与错误码分配见 [响应与错误码约定](../05-规范/响应与错误码约定.md)。

## 1. 数据库层当前实际状态

### `test_runs.status`

当前代码真实写入和消费的任务级状态为：

- `pending`
- `running`
- `pausing`
- `paused`
- `terminating`
- `canceling`
- `completed`
- `terminated`
- `canceled`
- `failed`

说明：

- 这是当前数据库层和对外接口共同使用的稳定状态值
- 旧模型注释里出现的 `finished_success / finished_error` 不代表当前实现

### `run_datasets.status`

当前任务数据集快照实际参与流转的状态为：

- `pending`
- `running`
- `completed`
- `terminated`
- `canceled`
- `failed`

说明：

- 创建 run 图时初始化为 `pending`
- 当前数据集执行时切为 `running`
- 任务完成或被终止时会收敛到对应终态

### `sample_executions.status`

当前执行级状态为：

- `pending`
- `dispatching`
- `executing`
- `verifying`
- `done`
- `error`

### `run_reports.report_status`

当前实际生产的报告状态：

- `available`

当前仅模型预留、尚未进入主链的状态：

- `generating`
- `failed`

### `execution_summaries.final_label`

当前实际写入的结果标签：

- `needs_review`
- `timeout`
- `safe`
- `hijacked`

当前只在模型注释中出现、尚未被运行链实际写出的预留示例：

- `refused`

### `agents.status`

当前 Agent 注册配置实际参与流转的状态为：

- `draft`
- `verifying`
- `active`
- `invalid`
- `archived`

说明：

- 新建 Agent 默认为 `draft`
- 验证通过后变为 `active`，只有 `active` Agent 可以创建 API 评测
- 验证失败会变为 `invalid`
- `archived` Agent 不再允许验证或提交新评测；历史评测继续使用创建时冻结的 Agent 快照

## 2. 规则与提交枚举

### `sample_oracles.oracle_kind`

| 值 | 含义 |
| --- | --- |
| `1` | `success` |
| `2` | `harm` |

### `submit_method`

当前公开提交方式：

- `api`

说明：

- `test_runs.submit_method` 直接存稳定 text code
- `docker` 只属于历史/预留值，当前不作为公开提交能力

### worker dispatch mode

当前 worker dispatch 适配模式：

- `external_agent_api`
- `synthetic_local`
- `deferred`

说明：

- API 评测主链使用创建评测时冻结的 Agent 配置进入 `external_agent_api`
- 本地脚本化联调可使用 `synthetic_local` 闭合 runtime 验证
- `deferred` 保留等待 runtime finalize 的框架能力，不是当前公开提交默认模式

## 3. 样本元数据稳定 code

以下 code 当前都采用稳定 ASCII 标识，常见形式是字母、数字和下划线。

### `dataset_source_code`

- 主维护源：`dataset_sources.code`

### `attack_delivery_type_code`

- 主维护源：`attack_delivery_types.code`
- 当前示例：`indirect_prompt_injection`

### `risk_category_code`

- 主维护源：`risk_categories.code`
- 当前示例：`confidentiality`、`integrity`

### `risk_subtype_code`

- 主维护源：`risk_subtypes.code`
- 当前示例：`B2_cloud_file_modification`

### `asset_type_code`

- 主维护源：`asset_types.code`

说明：

- 旧样本里的 `attack_delivery / primary_risk / secondary_risk` 只属于兼容导入别名，不是当前正式字段名
