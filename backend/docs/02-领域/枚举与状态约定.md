# 枚举与状态约定

本文档是后端状态值、动作值和稳定 code 的主维护文档。
统一响应包裹与错误码分配见 [响应与错误码约定](../05-规范/响应与错误码约定.md)。

## 1. 数据库层状态

### `test_runs.status`

当前模型注释中可见的任务级状态示例：

- `pending`
- `executing`
- `finished_success`
- `finished_error`

说明：

- 这是数据库层内部状态
- 若对外接口需要更细粒度公开状态，应在 API 层做映射，不直接暴露数据库值

### `sample_executions.status`

当前模型注释中可见的执行级状态：

- `pending`
- `dispatching`
- `executing`
- `verifying`
- `done`
- `error`

### `run_reports.report_status`

当前模型注释中可见的报告状态：

- `generating`
- `available`
- `failed`

### `execution_summaries.final_label`

当前模型注释中可见的最终标签：

- `safe`
- `hijacked`
- `timeout`
- `refused`

## 2. 规则与提交枚举

### `sample_oracles.oracle_kind`

| 值 | 含义 |
| --- | --- |
| `1` | `success` |
| `2` | `harm` |

### `submit_method`

当前联调契约中的提交方式：

- `api`
- `docker`

约定：

- 数据库字段 `test_runs.submit_method` 直接存稳定 text code
- 旧文档中出现的其他示例值仅视为历史口径，不再作为当前联调契约

## 3. 样本元数据稳定 code

### `attack_delivery`

- 主维护源：`attack_delivery_types.code`
- 规则：小写蛇形命名
- 当前示例：`indirect_prompt_injection`

### `primary_risk`

- 主维护源：`risk_categories.code`
- 规则：小写蛇形命名
- 当前示例：`confidentiality`、`integrity`

### `secondary_risk`

- 主维护源：`risk_subtypes.code`
- 规则：小写蛇形命名
- 当前示例：`local_file_modification`

## 4. 对外公开状态与动作

以下值用于 `share/` 中的跨端接口契约。

### 公开任务状态

- `pending`
- `running`
- `pausing`
- `paused`
- `terminating`
- `canceling`
- `completed`
- `terminated`
- `canceled`
- `failed`

### 终态原因

- `completed`
- `terminated_by_user`
- `auto_terminated_after_pause_timeout`
- `canceled_by_user`
- `failed`

### 任务动作

- `pause`
- `resume`
- `terminate`
- `cancel`
