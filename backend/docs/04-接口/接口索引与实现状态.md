| 路由 | 说明 | 实现状态 | 入口 |

## 3. 当前已实现路由清单

| 路由 | 鉴权 | 入口文件 | 备注 |
| --- | --- | --- | --- |
| `POST /api/v1/auth/login` | 否 | `app/modules/auth/router.py` | 支持用户名或邮箱登录 |
| `POST /api/v1/auth/register` | 否 | `app/modules/auth/router.py` | 注册成功后直接返回 token 与用户信息 |
| `GET /api/v1/auth/me` | 是 | `app/modules/auth/router.py` | 读取当前登录用户 |
| `GET /api/v1/user/profile` | 是 | `app/modules/user/router.py` | 个人资料页初始化 |
| `PUT /api/v1/user/profile` | 是 | `app/modules/user/router.py` | 当前允许修改用户名和密码，不允许修改邮箱 |
| `POST /api/v1/user/avatar` | 是 | `app/modules/user/router.py` | `multipart/form-data` 上传头像 |
| `GET /api/v1/datasets/catalog` | 否 | `app/modules/datasets/router.py` | 返回公开数据集目录 |
| `GET /api/v1/datasets/{datasetId}` | 否 | `app/modules/datasets/router.py` | 返回单个公开数据集详情 |
| `GET /api/v1/agents/submit-meta` | 否 | `app/modules/submissions/router.py` | 提交页初始化元数据 |
| `POST /api/v1/agents/precheck` | 是 | `app/modules/submissions/router.py` | 提交前校验，不落库 |
| `POST /api/v1/agents/submit` | 是 | `app/modules/submissions/router.py` | 创建评测任务，由独立 worker 领取执行 |
| `GET /api/v1/evaluations` | 是 | `app/modules/evaluations/router.py` | 当前用户评测列表 |
| `GET /api/v1/evaluations/{evaluationId}` | 是 | `app/modules/evaluations/router.py` | 当前用户评测详情快照 |
| `POST /api/v1/evaluations/{evaluationId}/actions` | 是 | `app/modules/evaluations/router.py` | pause / resume / terminate / cancel |

## 4. 更新规则

- 新增或变更跨端业务接口时，先更新 `share/API接口协议.md`，再按需更新补充说明和本文
- 接口实现落地后，从“未实现”改为“已实现”，同时补齐对应入口文件
- 若仅是后端内部调试接口，不写入 `share/`，但应评估是否需要记录到本文
