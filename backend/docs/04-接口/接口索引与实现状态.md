# 接口索引与实现状态

本文档只维护接口分组、实现状态和后端入口文件。公开接口的实际行为以 `app/modules/*` 下 router / schemas / service、`tests/api/` 以及烟测脚本为准。

- `share/` 下文档可作为前后端沟通参考，但不作为后端实现真相源
- 统一响应包裹和错误码分配见 [响应与错误码约定](../05-规范/响应与错误码约定.md)
- 状态值和动作值见 [枚举与状态约定](../02-领域/枚举与状态约定.md)

## 1. 服务入口

| 路由           | 说明          | 实现状态 | 入口                |
| -------------- | ------------- | -------- | ------------------- |
| `GET /`        | 根路径        | 已实现   | `app/main.py`       |
| `GET /api/`    | API 根路径    | 已实现   | `app/api/router.py` |
| `GET /api/v1/` | API v1 根路径 | 已实现   | `app/api/v1/api.py` |

以上入口只用于服务可达性与开发调试，不作为业务接口契约主文档。

## 4. 已移除的旧提交接口

旧版把提交元数据、预检和提交挂在 Agent 相关路由下的三类接口当前不再挂载，也不再作为对外契约。

替代关系：

- 提交页元数据：`GET /api/v1/evaluations/meta`
- 提交校验：`POST /api/v1/evaluations/validate`
- 创建评测：`POST /api/v1/evaluations`
- 评分查询/重算：`GET /api/v1/evaluations/{evaluationId}/score`、`POST /api/v1/evaluations/{evaluationId}/score/recalculate`

## 5. 当前未实现的公开接口能力

以下能力经常被前端或评审误认为已具备，当前需要单独写清：

- 样本级 execution 列表与详情接口：未实现
- 独立产物下载或证据查询接口：未实现
- Docker 提交与运行期管理接口：未实现
- 报告文件下载接口：未实现，当前只有任务级 `summary_json`
- 排行榜历史快照查询和管理权限：未实现；当前榜单已支持未登录查询与匿名展示

## 6. 更新规则

- 新增或变更公开接口时，先更新本文中的路由分组与入口文件，再同步检查 `backend/README.md`、`tests/api/` 与烟测脚本是否仍与实现一致
- 需要对外同步给前端或评审方时，再按需评估是否更新 `share/` 下的沟通材料
- 若仅是后端内部调试接口，不写入 `share/`，但应评估是否需要记录到本文
