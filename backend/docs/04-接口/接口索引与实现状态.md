# 接口索引与实现状态

本文档只维护接口分组、实现状态、主契约文档和后端入口文件。

- 请求/响应示例主维护在 `share/`
- 统一响应包裹和错误码分配见 [响应与错误码约定](../05-规范/响应与错误码约定.md)
- 状态值和动作值见 [枚举与状态约定](../02-领域/枚举与状态约定.md)

## 1. 服务入口

| 路由 | 说明 | 实现状态 | 入口 |
| --- | --- | --- | --- |
| `GET /` | 根路径 | 已实现 | `app/main.py` |
| `GET /api/` | API 根路径 | 已实现 | `app/api/router.py` |
| `GET /api/v1/` | API v1 根路径 | 已实现 | `app/api/v1/api.py` |

以上入口只用于服务可达性与开发调试，不作为业务接口契约主文档。

## 3. 当前已实现路由清单

| 路由 | 鉴权 | 入口文件 | 备注 |
| --- | --- | --- | --- |
| `POST /api/v1/auth/login` | 否 | `app/api/v1/endpoints/auth.py` | 支持用户名或邮箱登录 |
| `POST /api/v1/auth/register` | 否 | `app/api/v1/endpoints/auth.py` | 注册成功后直接返回 token 与用户信息 |
| `GET /api/v1/auth/me` | 是 | `app/api/v1/endpoints/auth.py` | 读取当前登录用户 |
| `GET /api/v1/user/profile` | 是 | `app/api/v1/endpoints/user.py` | 个人资料页初始化 |
| `PUT /api/v1/user/profile` | 是 | `app/api/v1/endpoints/user.py` | 当前允许修改用户名和密码，不允许修改邮箱 |
| `POST /api/v1/user/avatar` | 是 | `app/api/v1/endpoints/user.py` | `multipart/form-data` 上传头像 |

## 4. 更新规则

- 新增或变更跨端业务接口时，先更新 `share/` 中对应主文档，再更新本文的实现状态与入口信息
- 接口实现落地后，从“未实现”改为“已实现”，同时补齐对应入口文件
- 若仅是后端内部调试接口，不写入 `share/`，但应评估是否需要记录到本文
