# 文档地图

本文档定义 `backend/` 文档体系的入口和导航方式。

## 1. 入口约定

- `backend/README.md`：后端项目入口，只写当前状态、启动方式、核心约束、文档索引
- `backend/TODO.md`：未完成事项、优先级和阻塞项
- `share/`：跨端接口契约主文档
- `backend/docs/`：后端内部说明文档与规范文档

## 2. 目录结构

```text
docs/
├── 01-总览/
│   ├── 文档地图.md
│   └── 后端架构说明.md
├── 02-领域/
│   ├── 测评领域说明.md
│   └── 枚举与状态约定.md
├── 03-数据/
│   ├── 数据库说明.md
│   └── 样本导入说明.md
├── 04-接口/
│   └── 接口索引与实现状态.md
└── 05-规范/
    ├── 响应与错误码约定.md
    └── 文档维护约定.md
```

## 3. 遇到问题先看哪里

- 想快速启动后端：看 [README.md](../../README.md)
- 想理解代码分层和请求链路：看 [后端架构说明](./后端架构说明.md)
- 想知道某组接口是否已经实现：看 [接口索引与实现状态](../04-接口/接口索引与实现状态.md)
- 想查数据库表职责、关系和字段语义：看 [数据库说明](../03-数据/数据库说明.md)
- 想查样本导入契约与 `task.json` 字段：看 [样本导入说明](../03-数据/样本导入说明.md)
- 想查测评生命周期、oracle 语义和结果解释：看 [测评领域说明](../02-领域/测评领域说明.md)
- 想查状态值、动作值和稳定 code：看 [枚举与状态约定](../02-领域/枚举与状态约定.md)
- 想查统一响应包裹和错误码分配：看 [响应与错误码约定](../05-规范/响应与错误码约定.md)
- 想判断某个事实应该写在哪个文档：看 [文档维护约定](../05-规范/文档维护约定.md)

## 4. 主维护边界

- 跨端接口契约主维护在 `share/`
- 后端代码结构、数据库、领域语义、导入规则、响应规范主维护在 `backend/docs/`
- 同一个事实只允许一个主维护文档，其他文档只链接，不复制整段内容
