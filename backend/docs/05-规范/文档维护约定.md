# 文档维护约定

本文档定义 `backend/` 文档体系的职责边界、事实唯一归属和更新触发规则。

## 1. 总原则

- 一个事实只在一个地方主维护，其他文档只链接，不复制整段内容
- `README.md` 和 `TODO.md` 只保留在 `backend/` 根目录
- `share/` 是跨端接口契约主文档目录
- `backend/docs/` 只维护后端内部说明、约束和索引

## 2. 事实唯一归属表

| 事实类型 | 主维护文档 |
| --- | --- |
| 后端项目入口、启动方式、核心约束、文档入口 | `backend/README.md` |
| 未完成事项、优先级、阻塞项 | `backend/TODO.md` |
| 后端文档导航 | `backend/docs/01-总览/文档地图.md` |
| 后端代码分层、请求链路、架构入口 | `backend/docs/01-总览/后端架构说明.md` |
| 测评生命周期、oracle 语义、领域对象边界 | `backend/docs/02-领域/测评领域说明.md` |
| 状态值、动作值、稳定 code | `backend/docs/02-领域/枚举与状态约定.md` |
| 数据表职责、关系、字段语义、约束 | `backend/docs/03-数据/数据库说明.md` |
| `task.json` 字段、导入归一化、入库映射 | `backend/docs/03-数据/样本导入说明.md` |
| 接口是否实现、入口文件、主契约文档索引 | `backend/docs/04-接口/接口索引与实现状态.md` |
| 统一响应包裹、错误码分配 | `backend/docs/05-规范/响应与错误码约定.md` |
| 用户接口契约 | `share/user接口.md` |
| 数据集与提交接口契约 | `share/database&submit接口.md` |
| 评测记录与报告接口契约 | `share/evaluations接口.md` |

## 3. 更新触发器

| 变更类型 | 必须同步更新 |
| --- | --- |
| 新增或变更跨端接口契约 | `share/` 对应接口文档 + `backend/docs/04-接口/接口索引与实现状态.md` |
| 接口从“规划中”变为“已实现” | `share/` 对应接口文档 + `backend/docs/04-接口/接口索引与实现状态.md` + `backend/README.md` |
| 响应包裹或错误码变化 | `backend/docs/05-规范/响应与错误码约定.md`，必要时同步 `share/` 对应接口文档 |
| 状态值、动作值、公开枚举变化 | `backend/docs/02-领域/枚举与状态约定.md`，必要时同步 `share/evaluations接口.md` 或 `share/database&submit接口.md` |
| 表结构、字段语义、主外键关系变化 | `backend/docs/03-数据/数据库说明.md` |
| 样本导入契约、归一化规则、入库映射变化 | `backend/docs/03-数据/样本导入说明.md` |
| 测评生命周期、oracle 语义、结果定义变化 | `backend/docs/02-领域/测评领域说明.md` |
| 文档目录结构或导航变化 | `backend/docs/01-总览/文档地图.md` + `backend/README.md` |
| 当前能力、启动方式、核心约束变化 | `backend/README.md` |
| 阶段优先级或阻塞变化 | `backend/TODO.md` |

## 4. 不再保留的旧职责

以下旧做法不再保留：

- 不再在 `backend/docs/` 维护完整的“联调接口草案”
- 不再单独维护“已实现 API 说明”与“未实现接口草案”两套正文文档
- 不再在多个文档中重复维护同一份状态枚举、错误码表或 `task.json` 字段表

## 5. 写法要求

- 优先写结论和可执行信息
- 路径、路由、字段名与代码保持一致
- 避免在非主维护文档复制整段表格或示例
- 文档名采用“主题 + 说明/约定/索引”的形式
- 若必须引用其他文档内容，使用链接而不是再次展开完整正文
