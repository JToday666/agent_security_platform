# 数据库说明

本文档面向后端开发，说明当前数据库中的表职责、关键关系、字段语义和重要约束。
状态值、动作值和稳定 code 口径见 [枚举与状态约定](../02-领域/枚举与状态约定.md)。

数据库目前可分为三块：

- 用户账户：`users`
- 测评基础数据：字典表、样本表、样本规则表
- 测评运行结果：任务、执行、判定、统计、报告

常见关系链：

- `test_runs -> run_samples -> sample_executions -> oracle_results / execution_summaries / execution_artifacts`
- `benchmark_samples -> sample_oracles`
- `risk_categories -> risk_subtypes -> benchmark_samples`

## 1. 用户账户

### `users`

- 用途：系统用户账户表
- 关键关系：被 `test_runs.user_id` 引用
- 字段：

| 字段 | 类型 | 含义 | 备注 |
| --- | --- | --- | --- |
| `id` | int | 用户主键 | PK |
| `username` | varchar(50) | 用户名 | 唯一、索引 |
| `email` | varchar(255) | 邮箱 | 唯一、索引 |
| `hashed_password` | varchar(255) | 密码哈希 | 非空 |
| `avatar_url` | varchar(512) | 头像地址 | 可空 |
| `is_active` | bool | 是否激活 | 默认 `true` |
| `is_superuser` | bool | 是否超级管理员 | 默认 `false` |
| `created_at` | timestamptz | 创建时间 | 非空 |
| `updated_at` | timestamptz | 更新时间 | 非空 |

- 补充约束：`username`、`email` 为账户唯一标识；登录逻辑当前支持用户名或邮箱。

## 2. 测评基础数据

| --- | --- | --- | --- |
| `id` | smallint | 来源主键 | PK |
| `code` | text | 来源编码 | 唯一、索引 |
| `name` | text | 展示名 | 非空 |
| `description` | text | 描述 | 可空 |
| `is_active` | bool | 是否启用 | 默认 `true` |
| `created_at` | timestamptz | 创建时间 | 非空 |

- 补充约束：适合作为静态字典表维护。

| 字段 | 类型 | 含义 | 备注 |

| `name` | text | 子类名称 | 非空 |

| `sort_order` | smallint | 排序值 | 可空 |

| `created_at` | timestamptz | 创建时间 | 非空 |

- 补充约束：唯一键为 `category_id + code`。

- 用途：风险子类的展示元数据

- 字段：

| 字段 | 类型 | 含义 | 备注 |
| --- | --- | --- | --- |
| `subtype_id` | int | 关联风险子类 | PK、FK |

| `highlights` | jsonb | 重点列表 | 默认空数组 |
| `scenarios` | jsonb | 典型场景列表 | 默认空数组 |
| `resources` | jsonb | 外部资源列表 | 默认空数组 |
| `media` | jsonb | 图片/视频资源 | 默认空数组 |
| `updated_at` | timestamptz | 更新时间 | 非空 |

- 补充约束：多个 JSONB 字段都用于前端展示，不参与运行判定。

- 补充约束：用于描述样本攻击目标涉及的资产对象。

### `benchmark_samples`

- 用途：核心测评样本表
- 关键关系：
  - `dataset_source_id -> dataset_sources.id`
  - `attack_delivery_type_id -> attack_delivery_types.id`
  - `risk_subtype_id -> risk_subtypes.id`
  - `asset_type_id -> asset_types.id`
  - 被 `sample_oracles.sample_id_ref`、`run_samples.sample_id_ref`、`sample_executions.sample_id_ref`、`sample_difficulty_stats.sample_id_ref` 引用
- 字段：

| 字段 | 类型 | 含义 | 备注 |
| --- | --- | --- | --- |
| `id` | bigint | 样本主键 | PK |
| `dataset_source_id` | smallint | 样本来源 | FK、索引 |
| `sample_id` | text | 来源内样本编号 | 与 `dataset_source_id` 组成唯一键 |
| `sample_name` | text | 样本名称 | 可空 |
| `resource_path` | text | 资源目录路径 | 非空 |
| `entry_path` | text | 入口路径 | 非空 |
| `user_goal` | text | 表面用户目标 | 非空 |
| `attacker_goal` | text | 攻击目标 | 可空 |
| `attacker_is_user` | bool | 攻击者是否为用户 | 非空 |
| `attack_delivery_type_id` | smallint | 攻击投递方式 | FK、索引 |
| `risk_subtype_id` | int | 风险子类 | FK、索引 |
| `risk_level` | smallint | 风险等级 | 索引，范围 1-3 |
| `attack_level` | smallint | 攻击难度等级 | 索引，范围 1-3 |
| `difficulty_seed` | numeric(4,3) | 初始难度权重 | 范围 0-1 |
| `difficulty_score` | numeric(4,3) | 动态难度分数 | 索引，范围 0-1 |
| `difficulty_updated_at` | timestamptz | 难度更新时间 | 可空 |
| `asset_type_id` | int | 资产类型 | FK、可空、索引 |
| `expected_safe_behavior` | text | 期望安全行为 | 非空 |
| `is_active` | bool | 是否启用 | 默认 `true`、索引 |
| `created_at` | timestamptz | 创建时间 | 非空 |
| `updated_at` | timestamptz | 更新时间 | 非空 |

- 补充约束：核心唯一键为 `dataset_source_id + sample_id`；难度与等级字段都有显式范围约束。

### `sample_oracles`

- 用途：样本级评判规则表
- 关键关系：`sample_id_ref -> benchmark_samples.id`；被 `oracle_results.oracle_id` 引用
- 字段：

| 字段 | 类型 | 含义 | 备注 |
| --- | --- | --- | --- |
| `id` | bigint | 规则主键 | PK |
| `sample_id_ref` | bigint | 关联样本 | FK、索引 |
| `oracle_kind` | smallint | 规则类型 | 取值见枚举与状态约定 |
| `seq_no` | smallint | 同类规则顺序 | 与 `sample_id_ref + oracle_kind` 组成唯一键 |
| `display_text` | text | 人类可读说明 | 非空 |
| `evaluator_type` | text | 评估器类型 | 非空 |
| `evaluator_config` | jsonb | 评估器配置 | 非空、JSONB |
| `is_active` | bool | 是否启用 | 默认 `true` |
| `created_at` | timestamptz | 创建时间 | 非空 |
| `updated_at` | timestamptz | 更新时间 | 可空 |

- 补充约束：唯一键为 `sample_id_ref + oracle_kind + seq_no`。

## 3. 测评运行结果

### `test_runs`

- 用途：测评任务主表
- 关键关系：`user_id -> users.id`；被 `run_samples.run_id`、`sample_executions.run_id`、`run_reports.run_id` 引用
- 字段：

| 字段 | 类型 | 含义 | 备注 |
| --- | --- | --- | --- |
| `id` | bigint | 任务主键 | PK |
| `user_id` | int | 发起用户 | FK、索引 |
| `public_id` | text | 对外任务编号 | 唯一 |
| `agent_name` | text | 被测 Agent 名称 | 非空 |
| `description` | text | 任务备注 | 可空 |
| `submit_method` | text | 提交方式 | 非空，取值见枚举与状态约定 |
| `public_to_leaderboard` | bool | 是否公开到排行榜 | 默认 `true` |
| `request_id` | text | 幂等请求号 | 与 `user_id` 组成唯一键 |
| `agent_base_url` | text | Agent 基础地址 | 非空 |
| `credential_ref` | text | 凭证引用 | 可空 |
| `status` | text | 任务状态 | 索引，取值见枚举与状态约定 |
| `sample_query_snapshot` | jsonb | 样本筛选快照 | 非空、JSONB |
| `execution_config` | jsonb | 执行配置 | 非空、JSONB |
| `total_samples` | int | 样本总数 | 默认 `0` |
| `completed_samples` | int | 已完成样本数 | 默认 `0` |
| `success_count` | int | 系统级执行成功数 | 默认 `0` |
| `failed_count` | int | 执行失败数 | 默认 `0` |
| `created_at` | timestamptz | 创建时间 | 索引 |
| `updated_at` | timestamptz | 更新时间 | 索引 |
| `started_at` | timestamptz | 开始执行时间 | 可空 |
| `finished_at` | timestamptz | 结束时间 | 可空 |
| `finalization_reason` | text | 结束原因 | 可空 |
| `pause_used` | bool | 是否已用过暂停机会 | 默认 `false` |
| `pause_deadline_at` | timestamptz | 暂停恢复截止时间 | 可空 |
| `requested_action` | text | 待执行的用户动作 | 可空 |
| `requested_action_at` | timestamptz | 最近一次动作请求时间 | 可空 |
| `claimed_by` | text | 当前领取该任务的 worker 标识 | 可空、索引 |
| `claimed_at` | timestamptz | worker 首次领取时间 | 可空 |
| `claim_heartbeat_at` | timestamptz | worker 最近一次心跳时间 | 可空、索引 |

- 补充约束：唯一键为 `user_id + request_id`；`status` 表示任务级生命周期；`claimed_by + claim_heartbeat_at` 用于 worker 领取与超时回收。

### `run_samples`

- 用途：任务与样本的映射表
- 关键关系：
  - `run_id -> test_runs.id`
  - `sample_id_ref -> benchmark_samples.id`
  - 被 `sample_executions.run_sample_id` 引用
- 字段：

| 字段 | 类型 | 含义 | 备注 |
| --- | --- | --- | --- |
| `id` | bigint | 记录主键 | PK |
| `run_id` | bigint | 任务 ID | FK、索引 |
| `sample_id_ref` | bigint | 样本 ID | FK、索引 |
| `order_no` | int | 执行顺序 | 可空 |
| `created_at` | timestamptz | 入队时间 | 非空 |

- 补充约束：唯一键为 `run_id + sample_id_ref`，避免同一任务重复关联同一样本。

### `sample_executions`

- 用途：样本单次执行记录
- 关键关系：
  - `run_id -> test_runs.id`
  - `run_sample_id -> run_samples.id`
  - `sample_id_ref -> benchmark_samples.id`
  - 被 `execution_artifacts.sample_execution_id`、`oracle_results.sample_execution_id`、`execution_summaries.sample_execution_id` 引用
- 字段：

| 字段 | 类型 | 含义 | 备注 |
| --- | --- | --- | --- |
| `id` | bigint | 执行主键 | PK |
| `run_id` | bigint | 所属任务 | FK、索引 |
| `run_sample_id` | bigint | 任务样本映射 | FK、索引 |
| `sample_id_ref` | bigint | 样本 ID | FK、索引 |
| `status` | text | 执行状态 | 索引，取值见枚举与状态约定 |
| `retry_no` | smallint | 重试序号 | 首次为 0 |
| `work_dir` | text | 工作目录 | 可空 |
| `entry_url` | text | 实际投递入口 | 可空 |
| `environment_ref` | text | 环境标识 | 可空 |
| `started_at` | timestamptz | 开始时间 | 可空 |
| `finished_at` | timestamptz | 结束时间 | 可空 |
| `error_message` | text | 错误摘要 | 可空 |
| `created_at` | timestamptz | 创建时间 | 索引 |
| `updated_at` | timestamptz | 更新时间 | 非空 |

- 补充约束：唯一键为 `run_sample_id + retry_no`；`run_id` 是冗余字段，主要为了聚合查询。

### `execution_artifacts`

- 用途：执行过程产物表
- 关键关系：`sample_execution_id -> sample_executions.id`
- 字段：

| 字段 | 类型 | 含义 | 备注 |
| --- | --- | --- | --- |
| `id` | bigint | 产物主键 | PK |
| `sample_execution_id` | bigint | 所属执行记录 | FK、索引 |
| `artifact_type` | text | 产物类型 | 非空 |
| `storage_uri` | text | 存储地址 | 非空 |
| `metadata` | jsonb | 元信息 | 字段名在模型中映射为 `artifact_metadata` |
| `created_at` | timestamptz | 创建时间 | 非空 |

- 补充约束：常用查询维度是 `sample_execution_id + artifact_type`；`metadata` 用于截图、抓包、日志等附加信息。

### `oracle_results`

- 用途：单条 oracle 判定结果
- 关键关系：
  - `sample_execution_id -> sample_executions.id`
  - `oracle_id -> sample_oracles.id`
- 字段：

| 字段 | 类型 | 含义 | 备注 |
| --- | --- | --- | --- |
| `id` | bigint | 结果主键 | PK |
| `sample_execution_id` | bigint | 所属执行 | FK、索引 |
| `oracle_id` | bigint | 规则 ID | FK、索引 |
| `matched` | bool | 是否命中 | 非空 |
| `score` | numeric(4,3) | 判定分数 | 可空，范围 0-1 |
| `evidence_summary` | text | 证据摘要 | 可空 |
| `evidence_ref` | jsonb | 证据引用 | 可空、JSONB |
| `evaluator_version` | text | 评估器版本 | 可空 |
| `created_at` | timestamptz | 创建时间 | 非空 |

- 补充约束：唯一键为 `sample_execution_id + oracle_id`；`matched` 和 `score` 共同表达单条规则命中情况。

### `execution_summaries`

- 用途：单次执行的聚合判定结果
- 关键关系：`sample_execution_id -> sample_executions.id`
- 字段：

| 字段 | 类型 | 含义 | 备注 |
| --- | --- | --- | --- |
| `id` | bigint | 汇总主键 | PK |
| `sample_execution_id` | bigint | 所属执行 | FK、唯一、索引 |
| `task_completed` | bool | 是否完成良性任务 | 非空 |
| `harm_detected` | bool | 是否探测到安全损害 | 非空 |
| `summary_text` | text | 人类可读总结 | 可空 |
| `final_label` | text | 最终标签 | 可空，取值见枚举与状态约定 |
| `created_at` | timestamptz | 创建时间 | 非空 |

- 补充约束：一条执行记录只允许一条汇总结果。

### `sample_difficulty_stats`

- 用途：样本难度统计缓存表
- 关键关系：`sample_id_ref -> benchmark_samples.id`
- 字段：

| 字段 | 类型 | 含义 | 备注 |
| --- | --- | --- | --- |
| `sample_id_ref` | bigint | 样本 ID | PK、FK |
| `valid_execution_count` | int | 有效执行次数 | 默认 `0`、非负 |
| `harm_count` | int | 损害触发次数 | 默认 `0`、非负 |
| `safe_completion_count` | int | 安全完成次数 | 默认 `0`、非负 |
| `harm_rate` | numeric(5,4) | 损害率 | 范围 0-1 |
| `safe_completion_rate` | numeric(5,4) | 安全完成率 | 范围 0-1 |
| `inferred_difficulty` | numeric(4,3) | 推断难度 | 范围 0-1 |
| `algorithm_version` | text | 统计算法版本 | 非空 |
| `last_execution_at` | timestamptz | 最近执行时间 | 可空、索引 |
| `updated_at` | timestamptz | 更新时间 | 索引 |

- 补充约束：这是一张统计缓存表，不直接代表单次执行结果。

### `run_reports`

- 用途：任务级报告表
- 关键关系：`run_id -> test_runs.id`
- 字段：

| 字段 | 类型 | 含义 | 备注 |
| --- | --- | --- | --- |
| `id` | bigint | 报告主键 | PK |
| `run_id` | bigint | 任务 ID | FK、唯一、索引 |
| `report_status` | text | 报告状态 | 索引，取值见枚举与状态约定 |
| `summary_json` | jsonb | 汇总摘要 | 可空、JSONB |
| `report_uri` | text | 报告文件地址 | 可空 |
| `created_at` | timestamptz | 创建时间 | 非空 |
| `updated_at` | timestamptz | 更新时间 | 可空 |

- 补充约束：一条任务只允许一条报告；`summary_json` 用于结构化汇总，`report_uri` 用于离线报告文件。
