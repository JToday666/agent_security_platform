# 数据库说明

本文档面向后端开发，说明当前数据库中的表职责、关键关系、字段语义和重要约束。
状态值、动作值和稳定 code 口径见 [枚举与状态约定](../02-领域/枚举与状态约定.md)。

数据库当前分为四块：

- 用户账户：`users`
- 测评基础数据：字典表、样本表、样本规则表
- 测评运行态：任务、数据集快照、样本执行、产物、摘要
- 预留统计与报告：`oracle_results`、`sample_difficulty_stats`、`run_reports`

常见关系链：

- `test_runs -> run_datasets / run_samples -> sample_executions -> execution_artifacts / oracle_results / execution_summaries`
- `benchmark_samples -> sample_oracles`
- `risk_categories -> risk_subtypes -> benchmark_samples`

## 1. 用户账户

### `users`

- 用途：系统用户账户表
- 当前生产来源：`auth`、`user` 模块
- 关键关系：被 `test_runs.user_id` 引用

| 字段 | 类型 | 含义 | 备注 |
| --- | --- | --- | --- |
| `id` | int | 用户主键 | PK |
| `username` | varchar(50) | 用户名 | 唯一、索引 |
| `email` | varchar(255) | 邮箱 | 唯一、索引 |
| `hashed_password` | varchar(255) | 密码哈希 | 非空 |
| `avatar_url` | varchar(512) | 头像地址 | 可空 |
| `is_active` | bool | 是否激活 | 默认 `true` |
| `is_superuser` | bool | 是否超级管理员 | 默认 `false` |
| `created_at` | timestamptz | 创建时间 | 非空 |
| `updated_at` | timestamptz | 更新时间 | 非空 |
